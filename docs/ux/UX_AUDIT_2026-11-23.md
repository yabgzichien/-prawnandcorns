# XMUM Compass UX review

**Date:** 23 November 2026
**Branch reviewed:** `feat/compass-planning-mvp`
**Scope:** Copy style, Gemini student planning, review and confirmation experience
**Method:** Source inspection, existing local test outcomes, Kit-derived quality gates

## Findings and decisions

| ID | Evidence | Impact | Action | Status |
| --- | --- | --- | --- | --- |
| UX-001 | Dozens of decorative separators in UI components and fictional task titles | Inconsistent tone and awkward copy when exported | Replace text with natural labels and add a source check | Implemented in this branch |
| UX-002 | The Gemini API can generate fresh prose not represented in source files | The model could reintroduce unwanted punctuation | Instruct the model and normalize display copy | Implemented; unit tested |
| UX-003 | Browser localStorage may contain study sessions from earlier demo versions | Old titles survive even after source copy changes | Keep IDs and times, migrate visible titles from known task IDs | Implemented; unit tested |
| UX-004 | Current source already requires explicit review and provides confirmation and rejection | Student controls when a study plan is committed | Preserve validation and the decision gate during copy changes | Protected by existing planning tests |
| UX-005 | Study-plan success is visible in the card and on the Home dashboard | User needs reliable confirmation of local-only persistence | Keep status copy explicit and check refresh on a real browser | Requires manual verification after update |
| UX-006 | Sample Moodle sync UX exists without official integration | User may mistake sample data for a live account connection | Review and make demo-only onboarding unmistakable | Follow-up, out of this copy pass |

## Relevant kit patterns

- **UX-STATUS-001:** Saved, failed and unavailable outcomes need distinct messages and appropriate next actions. Make the save destination clear.
- **UX-PREF-001:** Persistence scope must match the effect visible after reload. Browser-local sessions are not cloud sync.
- **Responsive React guidance:** Inspect narrow widths, scroll access, focus and state lifetime, not just desktop screenshots.
